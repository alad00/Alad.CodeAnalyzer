# ALAD0110

**Id**: ALAD0110\
**Titolo**: API sperimentali\
**Categoria**: Visibilità\
**Gravità**: Error

Si verifica quando viene fatto uso di API sperimentali che potrebbero cambiare o
essere rimosse in futuro, potenzialmente senza preavviso e senza essere
documentate.


## Esempio

```csharp
void Test() {
  ExperimentalClass x = new(); // ALAD0110
}
```


## Soluzione

Riportare l'attributo `[Experimental(…)]` nel chiamante per renderlo a sua volta
sperimentale. Al posto di `MY_API_EXPERIMENTAL`, utilizzare un codice
diagnostico univoco per questo specifico set di API sperimentali.

```csharp
[Experimental("MY_API_EXPERIMENTAL", UrlFormat = "https://bit.ly/ALAD0110")]
void Test() {
  ExperimentalClass x = new(); // OK
}
```

Oppure sopprimere questo messaggio per l'intero progetto. Il codice diagnostico
potrebbe non coincidere con `ALAD0110`, indicare il codice diagnostico visibile
nel messaggio di errore.

```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);ALAD0110</NoWarn>
</PropertyGroup>
```

Oppure sopprimere questo messaggio direttamente nel file. Il codice diagnostico
potrebbe non coincidere con `ALAD0110`, indicare il codice diagnostico visibile
nel messaggio di errore.

```csharp
void Test() {
#pragma warning disable ALAD0110
  ExperimentalClass x = new(); // OK
#pragma warning restore ALAD0110
}
```
