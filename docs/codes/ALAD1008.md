# ALAD1008

**Id**: ALAD1008\
**Titolo**: Caratteri speciali in un nome\
**Categoria**: Convenzioni di denominazione\
**Gravità**: Warning

Si verifica quando vengono utilizzati caratteri speciali in un nome.


## Esempio

```csharp
class Entità { // ALAD1008
  public int 時間無駄しね { get; set; } // ALAD1008
}

```


## Soluzione

Utilizzare solo lettere, numeri, o underscore. Non usare accenti o modificatori.

```csharp
class Entity { // OK
  public int DoNotWasteYourTime { get; set; } // OK
}
```
